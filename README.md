# 건강이 스케줄 — 앱 (ver2-2)

주간·월간 일정과 저녁 학습 체크리스트. 홈 화면에 추가하면 독립 실행되고, 오프라인에서도 열립니다.

## 파일

```
index.html            앱 전부 (화면 + 로직)
manifest.webmanifest  앱 이름·아이콘·실행 모드
sw.js                 서비스 워커 — 오프라인 캐시
app-config.js         동기화 설정 (기본은 이 기기에만 저장)
cloud-store.js        Firebase 저장 어댑터 (설정이 있을 때만 동작)
icons/                192 · 512 · maskable · apple-touch · favicon
```

## 기능

**주간 달력** — 개학(8/21)부터 종업(1/7)까지 주 단위로 넘겨 봅니다. 학기 밖으로는 넘어가지 않습니다. 요일 카드에 그날 교시·학원·학습이 모두 들어 있고, 학습 완료는 **카드에서 바로 눌러 켜고 끕니다**.

**월간 달력** — 상단 「주간 / 월간」으로 전환합니다. 요일 카드를 주간과 **같은 함수로** 그리므로 어느 쪽에서 체크하든 즉시 같은 내용이 보입니다. 한 달씩 넘기고, 한 달치는 스크롤로 이어집니다.

**간략히 보기** (월간) — 학교 교시는 감추고, 학원 일정은 그대로, 학습은 아이콘만 남깁니다.

**요일 카드 [수정]** — 보강·휴원·전체 휴원은 그대로. 여기에 더해
- **특별 학습** — 그날 하루만 있는 항목을 추가·삭제합니다
- **매주 반복 학습** — 반복 목록에서 항목을 뺍니다

## 저장

기본은 **이 기기에만**(localStorage) 저장합니다. 설정 없이 바로 씁니다.

여러 기기에서 같은 기록을 보려면 `app-config.js` 에 Firebase 설정을 넣으세요. 넣는 순간 클라우드 어댑터가 끼워지고, 다른 기기의 변경이 실시간으로 반영됩니다. 클라우드를 쓰더라도 이 기기 사본은 항상 함께 남기 때문에 연결이 끊겨도 기록을 잃지 않습니다.

> **넣기 전에 확인하세요.** `app-config.js` 는 공개 주소에 그대로 올라갑니다. Firebase 웹 apiKey 는 비밀이 아니지만 그것만으로 접근을 막지 못합니다. **Firestore 보안 규칙에서 읽기·쓰기를 로그인 사용자로 제한**해야 주소를 아는 사람이 기록을 열거나 고치지 못합니다.

## 배포 (GitHub Pages)

1. 이 `app/` 내용을 **별도 public 저장소**의 루트에 올립니다
2. Settings → Pages → Source: `main` 브랜치 / `/ (root)`
3. `https://<계정>.github.io/<저장소>/` 로 열립니다

> `maya9898/main` 은 비공개로 두세요. `archive/` 에 개인정보가 든 원본이 있어, public 으로 바꾸면 git 히스토리에 남아 함께 공개됩니다.

## 알아 둘 점

- **글꼴**은 Google Fonts 에서 받습니다. 오프라인일 때는 기기 기본 한글 글꼴로 대체됩니다.
- 아티팩트에 쌓인 기존 체크 기록은 **자동으로 넘어오지 않습니다.** 새 앱에서 새로 시작합니다.
- 검색엔진에 잡히지 않도록 `noindex` 를 넣었지만, 주소를 아는 사람은 볼 수 있습니다.

## 데이터 고치기

앱이 보여 주는 내용은 전부 `data.json` 에 표로 들어 있습니다. 시간표를 바꾸거나 학습 항목을 늘리려면 **이 파일만** 고치면 되고, `app.js` 는 손대지 않아도 됩니다.

| 표 | 내용 |
|---|---|
| `학기` | 개학 · 종업 · 방학종료 |
| `분류` | 늘봄 / 방과후 / 학원 |
| `과목` | 과목별 분류 · 색 · 아이콘 |
| `시간표` | 요일 · 시작 · 끝 · 과목 |
| `정규수업` | 요일별 교시 |
| `하교시각` | 요일별 하교 시각 |
| `이동시간` | 간식 · 이동 구간 |
| `학사일정종류` | 일정 종류와 색 |
| `학사일정` | 2학년 학사 일정 |
| `학습항목` | 저녁 학습과 주간 목표 일수 |
| `배정규칙` | 주말 상한 · 같은 날 겹치지 않을 항목 |

`data.js` 는 이 표를 앱이 쓰는 형태로 옮기는 변환기입니다. 표에 문제가 있으면 (없는 과목을 시간표가 가리키는 등) 화면을 그리기 전에 어디가 잘못됐는지 알려 줍니다.

고친 뒤에는 `sw.js` 의 `CACHE` 번호를 올리고, `node qa/run.js static data` 로 확인하세요.

## 글꼴

Google Fonts 를 매번 불러오는 대신 `fonts/` 에 내장했습니다. 한글 1개(IBM
Plex Sans KR), 영문·숫자 1개(IBM Plex Mono), 각각 Regular 굵기 하나뿐입니다.
앱에서 실제로 쓰는 글자만 남긴 서브셋이라 둘 합쳐 44KB입니다.

다른 굵기가 필요한 곳(제목·강조)은 브라우저가 자동으로 두껍게 그려 줍니다.
완벽히 같지는 않지만, 이 정도 차이를 위해 파일을 늘리지 않기로 했습니다.

`data.json`에 서브셋에 없는 새 한글이 들어가면 그 글자만 기기 기본 글꼴로
보이고 나머지는 정상 동작합니다. 서브셋을 다시 만들려면:

```bash
node -e "..."   # app.js/index.html/data.json에서 쓰인 문자 전부 추출
fonttools subset <원본.woff2> --text-file=<추출한 문자 목록> --flavor=woff2 --output-file=<출력.woff2>
```

라이선스는 `fonts/LICENSE.txt` — 둘 다 SIL Open Font License 1.1(무료·상업 사용 가능).
