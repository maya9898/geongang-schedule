# 건강이 스케줄 — 앱 (ver2-2)

주간·월간 일정과 저녁 학습 체크리스트. 홈 화면에 추가하면 독립 실행되고, 오프라인에서도 열립니다.

## 파일

```
index.html            앱 전부 (화면 + 로직)
manifest.webmanifest  앱 이름·아이콘·실행 모드
sw.js                 서비스 워커 — 오프라인 캐시
app-config.js         동기화 설정 (기본은 이 기기에만 저장)
cloud-store.js        Firebase 저장 어댑터 (설정이 있을 때만 동작)
icons/                192 · 512 · maskable · apple-touch · favicon
```

## 화면 구성 (1뎁스 탭)

**캘린더** · **학사일정** · **시간표** — 세 개의 최상위 탭입니다. 「2학년 학사 일정」 전체 목록은 캘린더와 분리된 자기 탭에 있고, 캘린더 탭에는 그날그날 필요한 것만 남깁니다.

## 캘린더 탭

**주간 달력** — 개학(8/21)부터 종업(1/7)까지 주 단위로 넘겨 봅니다. 학기 밖으로는 넘어가지 않습니다. 요일 카드에 그날 교시·학원·학습이 모두 들어 있고, 학습 완료는 **카드에서 바로 눌러 켜고 끕니다**. 카드 안 리스트 글자 크기는 전부 통일되어 있습니다.

**월간 달력** — 상단 「주간 / 월간」으로 전환합니다. 요일 카드를 주간과 **같은 함수로** 그리므로 어느 쪽에서 체크하든 즉시 같은 내용이 보입니다. 한 달씩 넘기고, 페이지 스크롤 하나로 죽 이어집니다(달력 안에 따로 스크롤 상자를 두지 않습니다).

**간략히 보기** (월간) — 학교 교시는 감추고, 학원 일정은 그대로, 학습은 아이콘만 남깁니다.

**요일 카드 [수정]** — 카드 맨 아래에 있습니다. 누르면 그날 상세 편집 패널이 열립니다.
- **보강·휴원·전체 휴원** — 시간표 기본 일정을 그날만 조정
- **가족 일정** — 여행·체험학습처럼 하루 이상 이어지는 개인 일정을 추가·수정·삭제합니다. 시작~끝 날짜를 정하면 그 범위의 모든 날(주말 포함)에 표시되고, 달력 칸에도 **진한 배경 + 밝은 글자**로 눈에 띄게 배너가 뜹니다
- **특별 학습** — 그날 하루만 있는 항목을 추가·삭제합니다
- **매주 반복 학습** — 반복 목록에서 항목을 뺍니다

**팝업 두 개** — 캘린더 상단 오른쪽에 있습니다.
- **이번 주 학습 배정** — 반복 학습 항목을 요일별로 배정합니다. 팝업 안에서 고치고, **저장**하거나 **되돌리기**를 누르면 팝업이 닫힙니다
- **사용 방법 안내** — 학사일정 범례·색 안내와 저녁 학습 체크리스트 목표를 한 곳에 모아 둔 팝업입니다. 평소에는 접혀 있다가 필요할 때만 엽니다

## 학사일정 탭

2026학년도 학사일정 중 2학년에 해당하는 전체 목록입니다. 달력 각 날짜 칸에도 이미 표시되므로, 이 탭은 학기 전체를 한눈에 보고 싶을 때만 씁니다.

## 저장

기본은 **이 기기에만**(localStorage) 저장합니다. 설정 없이 바로 씁니다.

여러 기기에서 같은 기록을 보려면 `app-config.js` 에 Firebase 설정을 넣으세요. 넣는 순간 클라우드 어댑터가 끼워지고, 다른 기기의 변경이 실시간으로 반영됩니다. 클라우드를 쓰더라도 이 기기 사본은 항상 함께 남기 때문에 연결이 끊겨도 기록을 잃지 않습니다.

> **넣기 전에 확인하세요.** `app-config.js` 는 공개 주소에 그대로 올라갑니다. Firebase 웹 apiKey 는 비밀이 아니지만 그것만으로 접근을 막지 못합니다. **Firestore 보안 규칙에서 읽기·쓰기를 로그인 사용자로 제한**해야 주소를 아는 사람이 기록을 열거나 고치지 못합니다.

**로그인 방법 두 가지** — 헤더의 「동기화 켜기」는 구글 로그인, 「이메일로 로그인」은 구글 계정이 없는 기기를 위한 대안입니다. 이메일을 입력하면 로그인 링크가 메일로 가고, 그 링크를 누르면 앱으로 돌아와 자동으로 로그인됩니다. (이메일 링크 방식을 쓰려면 Firebase 콘솔 → Authentication → Sign-in method 에서 **이메일 링크**를 켜 두어야 합니다.)

## 가족 동기화 — 승인 방식

로그인만으로는 아이 기록에 접근하지 못합니다. **소유자(엄마)가 승인해야** 동기화가 시작됩니다.

1. 가족에게 앱 주소를 보냅니다
2. 그 사람이 **「동기화 켜기」** → 구글 계정으로 로그인 → 화면이 **「승인 대기 중」**이 되고, 그때까지는 자기 기기에만 저장됩니다
3. 소유자 앱 헤더의 **「가족」** 버튼에 빨간 숫자가 뜹니다 → 눌러서 **승인**
4. 승인하는 순간 그 사람 화면이 **새로고침 없이** 동기화로 바뀝니다

이후 누가 학습을 체크하거나 일정을 고쳐도 나머지 기기에 실시간으로 반영됩니다. 「가족」 팝업에서 **내보내기**를 누르면 그 사람은 즉시 권한을 잃습니다.

> **이메일을 화면에서 입력받지 않습니다.** 손으로 타이핑한 이메일은 신원 증명이 되지 않아서, 그대로 명단에 넣으면 주소를 아는 사람 누구나 아무 이메일이나 적고 들어올 수 있습니다. 구글 로그인이 검증한 이메일만 씁니다.

승인하는 사람(소유자)의 이메일은 **앱 코드에 두지 않습니다** — 이 폴더는 공개 주소에 그대로 올라가서 가족 주소가 노출되기 때문입니다. 이메일은 Firestore 보안 규칙에만 두고, 앱은 규칙이 자기 등록을 허락하는지로 소유자를 알아냅니다. 규칙 전문과 붙여넣는 곳은 저장소 루트의 **`FIREBASE-RULES.md`** — 콘솔 작업은 최초 1회로 끝나고, 이후 가족 추가·제거는 앱 안에서 합니다.

## 데이터 고치기

앱이 보여 주는 내용은 전부 `data.json` 에 표로 들어 있습니다. 시간표를 바꾸거나 학습 항목을 늘리려면 **이 파일만** 고치면 되고, `app.js` 는 손대지 않아도 됩니다.

| 표 | 내용 |
|---|---|
| `학기` | 개학 · 종업 · 방학종료 |
| `분류` | 늘봄 / 방과후 / 학원 |
| `과목` | 과목별 분류 · 색 · 아이콘 |
| `시간표` | 요일 · 시작 · 끝 · 과목 |
| `정규수업` | 요일별 교시 |
| `하교시각` | 요일별 하교 시각 |
| `이동시간` | 간식 · 이동 구간 |
| `학사일정종류` | 일정 종류와 색 |
| `학사일정` | 2학년 학사 일정 |
| `학습항목` | 저녁 학습과 주간 목표 일수 |
| `배정규칙` | 주말 상한 · 같은 날 겹치지 않을 항목 |

`data.js` 는 이 표를 앱이 쓰는 형태로 옮기는 변환기입니다. 표에 문제가 있으면 (없는 과목을 시간표가 가리키는 등) 화면을 그리기 전에 어디가 잘못됐는지 알려 줍니다.

고친 뒤에는 `sw.js` 의 `CACHE` 번호를 올리고, `node qa/run.js static data` 로 확인하세요.

## 글꼴

Google Fonts 를 매번 불러오는 대신 `fonts/` 에 내장했습니다. 한글 1개(IBM
Plex Sans KR), 영문·숫자 1개(IBM Plex Mono), 각각 Regular 굵기 하나뿐입니다.
앱에서 실제로 쓰는 글자만 남긴 서브셋이라 둘 합쳐 44KB입니다.

다른 굵기가 필요한 곳(제목·강조)은 브라우저가 자동으로 두껍게 그려 줍니다.
완벽히 같지는 않지만, 이 정도 차이를 위해 파일을 늘리지 않기로 했습니다.

`data.json`에 서브셋에 없는 새 한글이 들어가면 그 글자만 기기 기본 글꼴로
보이고 나머지는 정상 동작합니다. 서브셋을 다시 만들려면:

```bash
node -e "..."   # app.js/index.html/data.json에서 쓰인 문자 전부 추출
fonttools subset <원본.woff2> --text-file=<추출한 문자 목록> --flavor=woff2 --output-file=<출력.woff2>
```

라이선스는 `fonts/LICENSE.txt` — 둘 다 SIL Open Font License 1.1(무료·상업 사용 가능).
